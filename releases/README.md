# Docsera consumer releases

## 0.1.0

[Docsera 0.1.0](0.1.0/README.md) is the sole consumer release pair in this repository:

1. `0.1.0/docsera_application_0.1.0.xml` — install first as the scoped Docsera application update set.
2. `0.1.0/docsera_global_companion_0.1.0.xml` — install second as the Global companion update set.

Use the checksums and detailed import instructions in [0.1.0/README.md](0.1.0/README.md). The required order is scoped first, then Global.

No other XML in this repository is a supported consumer installation artifact.
