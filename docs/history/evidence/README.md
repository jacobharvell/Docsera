# Historical generated evidence

This directory preserves three immutable evidence artifacts from the RR-060 and RR-068 SDK conversion and owned-Global-package work. They are retained for their dated generated-output and package-identity evidence only; they do not define current installation, runtime, or release procedures.

- `RR-060 generated-output-inventory.json` records the generated-output inventory examined during RR-060.
- `RR-068-owned-global-package-manifest.json` and `RR-068-owned-global-sys-app.xml` preserve the owned Global package evidence examined during RR-068.

The associated RR task narratives are preserved in Git history. Superseded chronology is not retained solely to accompany these artifacts.
